# 刷题助手

基于本机题库与学习记录，查询刷题进度、错题本、校对清单，并生成一组练习题送进答题页的能力集合。

## 触发场景

用户原话举例（路由命中本技能）：

- "我有哪些题库？一共多少题啊"
- "我练得怎么样了，正确率大概多少"
- "错了哪些题，把易错题挑出来给我看看"
- "之前记的那些待修的题有没有，列一下"
- "帮我抽 20 道错题练练"
- "第一本书随便来几道，随机的那种"

## 不适用范围

- 导入试题文件、生成题库 → 不在本技能范围，需在小程序「文件库」里操作
- 删除题库、清空错题本、移除标记、改校对状态 → 不在本技能范围：这些是不可逆操作，应由用户在小程序页面里亲自确认后执行
- 修改题目内容或给出学科答案 → 不在本技能范围，题库内容由用户自己导入

## 前置条件

- 本机需已导入过题库。数据全部存在本机、不跨设备也不跨账号，若从未导入，各查询只会返回空态提示。

## 使用顺序

- 想先了解整体情况时调用 `getStudyOverview`；想看清具体有哪些题库（拿题库 id）时调用 `listSets`。
- 用户提到"某一本书 / 某个题库"时，先用 `listSets` 拿到对应题库，再把它传给 `listWrongItems` 或 `listErrataItems`。
- 要看具体错题与校对待修条目时调用 `listWrongItems`、`listErrataItems`；两者都有多个视图，默认分别落在"待攻克"与"待修"。
- 用户表达"练一练"时调用 `createPracticePlan`。题源选错题或标记题前，应先确认存在相应记录（可用 `getStudyOverview` 或 `listWrongItems` 确认），否则会得到空题源的提示。
- `createPracticePlan` 返回后由用户点击小程序卡片进入答题页，后续作答、判分、交卷都在小程序内完成，本技能不再介入。
